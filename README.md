# 网页版计算器 · Web Calculator

一个零依赖的网页计算器，单个 HTML 文件即可运行。

## 功能

- 四则运算：加 `+`、减 `−`、乘 `×`、除 `÷`
- 百分比 `%`、正负号 `+/−`
- 全部清除 `AC`
- 连续运算（输入运算符时自动结算上一步）
- 浮点数精度修正（`0.1 + 0.2` 得到 `0.3`）
- 除零保护（显示"错误"）
- 超长数字自动缩小字号 / 转科学计数法
- 完整键盘支持

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| `0`–`9` | 输入数字 |
| `.` | 小数点 |
| `+` `-` `*` `/` | 四则运算 |
| `Enter` 或 `=` | 求值 |
| `Backspace` | 退格 |
| `Esc` 或 `C` | 清除 |

## 使用方法

直接用浏览器打开 `index.html` 即可。无需构建、无需依赖。

也可以起一个本地静态服务：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术栈

纯 HTML + CSS + 原生 JavaScript，无任何第三方库。
